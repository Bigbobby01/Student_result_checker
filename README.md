# Student Result Checker
A beginner-friendly Python program that calculates student grades and determines whether a student passes or fails based on their score.
## Features
- Accepts a student's name and score.
- Calculates grades from A to F.
- Determines pass or fail status.
- Rejects scores outside the range of 0–100.
- Handles non-numeric input.
- Repeats the prompt when the input is invalid.
## Grade Scale
| Score | Grade |
|---|---|
| 70–100 | A |
| 60–69 | B |
| 50–59 | C |
| 45–49 | D |
| 0–44 | F |
A score of 45 or above is a pass.
## Technologies Used
- Python
- Functions
- Conditional statements
- Loops
- Exception handling
## How to Run
1. Install Python 3 if it isn't already installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:
   `python Student_result_checker.py`
